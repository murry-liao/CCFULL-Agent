# Third-party sources

## CCFULL

`vendor/ccfull/` contains unmodified files from [K. Hagino's CCFULL site](https://www2.yukawa.kyoto-u.ac.jp/~kouichi.hagino/ccfull.html). Retrieval URLs and SHA256 values are recorded in `vendor/ccfull/upstream.json`. The source header states a last modification date of February 16, 2015.

Reference: K. Hagino, N. Rowley, A. T. Kruppa, Comput. Phys. Commun. 123 (1999), 143–152. [DOI: 10.1016/S0010-4655(99)00243-X](https://doi.org/10.1016/S0010-4655(99)00243-X).

This project does not assign a new license to upstream files. Public download availability does not establish redistribution rights.

## Data and method references

- [NNDC ENSDF](https://www.nndc.bnl.gov/ensdf/) and [NuDat](https://www.nndc.bnl.gov/nudat3/): nuclear-structure sources for task-specific retrieval.
- [NNDC B(E2) Help](https://www.nndc.bnl.gov/be2/help.html): transition-direction and Weisskopf conventions.
- [NIST weighted least squares](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd432.htm): statistical-method reference.

Retrieved nuclear data and reaction-model parameters must retain their own provenance and citations. No reaction-specific literature collection is bundled.

Python dependencies retain their own licenses. No single project-wide distribution license is assigned.
