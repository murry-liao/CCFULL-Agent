# Known limitations

## 初版的完成范围

当前版本已具备“证据 → 候选方案 → 讨论确认 → 计算 → 校验 → 比较”的基本研究辅助流程。研究推理由当前对话 agent 提供；不是无需研究者参与的通用物理模型选择器。

## 物理接口

支持0⁺基态、每个核的振动或转子模型、一个弹核振动模式、最多两个不同多极性的靶核振动模式、靶核互激发的全选/不选，以及振动模式分别指定 βN/βC。

暂不支持：转移执行、自定义非谐矩阵、广义E2、靶核互激发的任意子集、转子与振动混合、β6、非零基态自旋。通道及径向网格受固定源程序容量限制。

低激发能、较大的 B(Eλ) 或 R4/2 单独都不足以决定模型。筛选阈值只是可调的候选排序规则。B(Eλ)只能在明确半径约定下给出 βC 幅值，不能直接给出 βN 或转子形变符号。

## 数据和统计

NuDat读取只解释当前支持的HTML表结构和普通数值/对称误差。复杂表达式、上下限、歧义自旋等保留为未解决项。缓存不是最新评价的保证；在线请求可能限流。

实验工具只处理明确的融合截面、对称1σ误差或正定协方差。不支持能量误差、非对称似然、任意观测量转换或外推。未提供归一化/能量偏移的 nuisance 参数拟合。

有限网格最优值只针对已评估点；缺失点和边界最优须单独检查。Δχ²离散支持集合不是置信区间或贝叶斯后验。不随包提供测量数据或合成实验数据。

## C0小幅概率越界

原版源码正常结束仍可能产生略大于1的积分概率。程序默认严格检查 P∈[-10⁻⁸,1+10⁻⁶]。是否接受小幅越界用于截面对比，需要结合来源、偏差幅度和截面稳定性作出具体判断。

`review-c0` 提供这种事后审阅机制，要求：原失败仅为概率边界、正常退出、两核均无耦合、源码/构建/文件及原计划匹配、其他检查通过、P≤1+2×10⁻⁴，并有研究者真实接受意见。上限是本机制的范围约束，不是普遍物理精度标准。

原文件、P值及严格失败状态不变；新记录独立存储。`compare` 可显式读取该记录并只画截面。实验比较与网格拟合目前仍要求严格通过的运行。较大越界、负概率异常或其他失败不得套用此例外。

软件功能存在不表示某个物理配置或结果已被研究者接受。

## 环境与物理验证

更换编译器或系统后应运行固定官方基准。通过该基准仅说明与参考值及所测径向设置的一致性，不能证明任意体系的耦合、势参数或障碍分布已获实验验证。
