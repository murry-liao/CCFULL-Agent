# Architecture

研究判断与数值执行分层：

```text
研究者 ↔ 对话 agent + ccfull-research skill
                   │ 可审阅配置与明确决定
                   ▼
                CLI / Python
     ┌─────────────┼──────────────┐
     ▼             ▼              ▼
结构数据/证据   模型校验/计划     实验数据/分析
                   │
          已确认计划 + 哈希校验
                   ▼
              Hagino CCFULL
                   │
            原始文件 → 校验 → 报告
```

| 模块 | 职责 |
|---|---|
| `model.py` | 配置 schema、单位与支持范围、输入卡和 stdin 回答、β换算 |
| `engine.py` | 固定源码校验、编译、计划/确认、隔离执行、输出验证、官方基准 |
| `structure.py` | NuDat读取、数值/分支提取、W.u.换算、候选态筛查 |
| `evidence.py` | 来源查询和有依据的候选方案整理 |
| `analysis.py` | 固定其他因素的比较、截面/平均角动量/障碍分布图 |
| `experiment.py` | 测量数据导入、显式单位/误差、协方差 χ² 和残差 |
| `planning.py` | 有限扫描、离散网格拟合、径向收敛及失败诊断 |
| `review.py` | 小幅C0概率越界的独立人工接受记录 |
| `cli.py` | 命令行入口 |

项目不包含独立 LLM 服务或任务调度器。技能决定研究步骤，工具约束可执行输入。确认记录是审计证据，不是身份认证或防篡改安全边界。

每组运行保存 config、Fortran输入、stdin回答、构建身份、确认记录、日志、原始输出和文件哈希。原版 `spin.dat` 表示平均角动量；`s-wave.dat` 包含多个分波的积分概率，不能根据文件名误称为完整自旋分布或仅l=0结果。

`status=succeeded` 表示通过本包装器的常规检查。人工接受的小幅C0例外另存为 `accepted_with_warning`，不改写原 `failed` 状态。分析时必须区分两者，并传播相应警告。
